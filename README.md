## ✨ Features

- 🎊 **Animated Birthday Page** — Bouncing letters & falling decorations
- 💌 **Love Letter Popup** — Typewriter-effect message with music
- 📸 **Memory Gallery** — Auto-scrolling photo memories
- 🎵 **3 Background Songs** — Unique music for each section
- 🌸 **Floating Hearts & Flowers** — Beautiful particle animations
- 📱 **Responsive Design** — Works on mobile & desktop
